# Be Light • I Am Light (प्रकाश स्वरूप बनो • मैं प्रकाश हूँ)

A mobile-friendly, meditative web experience designed for Diwali tables and quiet reflection. Created for the Brahma Kumaris serving in Vancouver, Surrey & Abbotsford, B.C., Canada.

## ✨ About the Experience
This project provides a peaceful digital getaway from the festival hustle into the light itself. Visitors are invited to look quietly into a flickering diya flame, steady their mind, and draw a personal Diwali virtue card from 8 bilingual virtues (Purity, Peace, Love, Joy, Power, Wisdom, Courage, Simplicity).

## 🎶 Features
- **Radiant Autumn-Leaf Gradient & Luminous Glow**
- **Photorealistic Flickering Diya Animation**
- **Bilingual Headings (English & Hindi)**
- **Interactive Virtue Card Draw (Coming Soon)**
- **Direct Links to the 'Come Into The Light' Song by Bliss**
- **Online Donation Portal & Event Info (World Peace Meditation on the 3rd Sunday of every month)**

## 🚀 Getting Started
To run or preview this project locally:
1. Clone the repository: `git clone https://github.com/your-username/i-am-light.git`
2. Open `index.html` in any modern web browser.
